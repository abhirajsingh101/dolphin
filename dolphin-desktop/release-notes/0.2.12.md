Dolphin 0.2.12 gives every project a companion.

- **A character per project.** Each project window now holds a small
  character drawn from the project. It shows how the project's sessions are
  doing (working, finished, needs a look, asleep) and says one line when a
  session finishes. Click it to open the project's Tasks tab; drag it
  anywhere inside its window. It steps back while you type in the terminal.
- **Chat in the Tasks tab.** The foot of the Tasks tab is now a chat with
  that project's companion. It knows the project's tasks and sessions and
  works only on that project; the chat on the right still covers everything.
- **Suggested tasks and Next up.** Ask what to do next and the companion's
  ideas appear in the list as dashed rows you can add or dismiss, and the
  task it would start with says why. Nothing is added until you click.
