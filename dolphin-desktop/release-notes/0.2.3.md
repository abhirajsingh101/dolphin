Dolphin 0.2.3 opens more than one window.

- **More windows.** File → New Window (⌘N on a Mac, Ctrl+Shift+N on Linux)
  opens another Dolphin window, for example one per screen. ⌘K, the Dock
  menu on a Mac and the app launcher on Linux offer New Window too. Every
  window shows the same machines, and two windows can show the same
  terminal at once.
- **Each window keeps its own layout.** Open project windows, tabs, the
  sidebar, the chat column and drafts belong to their window. A new window
  starts empty. Pins, unread markers and settings are shared, and a change
  in one window shows in the others at once.
- **Your windows come back.** Quitting saves every window, and they open
  again in their places. Closing one of several windows forgets it.
