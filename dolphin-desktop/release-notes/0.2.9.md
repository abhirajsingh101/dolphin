Dolphin 0.2.9 shows your downloads and keeps SSH machines steady.

- **Downloads in the top bar.** A file saved from a machine over SSH now
  shows a Downloads button beside the bell. Its ring fills as the file
  arrives, and the list shows the size so far, a progress bar and Cancel.
  A finished file offers Show in Finder (or your file manager).
- **No more flickering connections.** After the Mac's network changed, a
  machine over SSH could flip between connected and reconnecting about once
  a second, reattaching every terminal each time. Dolphin now keeps track of
  its SSH connection whatever this computer's hostname becomes.
