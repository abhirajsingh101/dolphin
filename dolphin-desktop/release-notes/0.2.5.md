Dolphin 0.2.5 gives this computer one memory of the work on every machine it connects to.

- **One memory for every machine.** With memory on, the brain on this
  computer now learns what happens on each machine Dolphin connects to over
  SSH: its projects and their folders, the agent turns that finished in them,
  and what that machine's own memory saved. Each machine has its own page,
  each project a dated timeline of finished work, and every saved fact says
  which machine it came from. This computer's own projects are included under
  its name. It catches up when a machine connects and every 10 minutes.
- **Memory stays lean.** Each machine's brain keeps a full copy of every
  write for a week, then a small stub, instead of a month.
- **Clear window buttons on a Mac.** The top bar leaves room for the red,
  yellow and green buttons, so the sidebar button no longer touches them.
