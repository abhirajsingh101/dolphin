Dolphin 0.2.1 makes Dolphin easier to install on a Mac and finds more of your projects.

- **Link a project finds your other folders.** On a server whose projects live
  outside your home folder, like `/work/<you>`, the folder picker now offers
  those folders next to home, with nothing to set up. Running sessions there
  can become projects too.
- **The Mac app opens.** Downloaded 0.2.0 Mac builds could be reported as
  "damaged" on Apple Silicon. Mac builds are now signed for the first open:
  macOS asks once, and System Settings → Privacy & Security → Open Anyway
  lets Dolphin in.
