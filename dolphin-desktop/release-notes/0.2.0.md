Dolphin 0.2.0 brings everything planned after 0.1.11 in one release.

## Reliability

- Terminals reconnect by themselves after a network drop or sleep, with no clicks.
- Dolphin notices when this computer's helper stops and starts it again; a
  failed computer no longer blocks your SSH machines.
- The helper times out a stuck tmux, bounds its terminal buffers, and explains
  a failed start with the end of its log.
- SSH machines are remembered after closing the window on macOS; installing
  the helper on a new machine shows upload progress and checks its checksum.

## Status

- Each session shows whether its agent is working, finished with something
  for you to read, failed, or idle, as a shape as well as a colour.
- Notifications come from the app itself: they arrive when the window is in
  the background or, on macOS, closed, and a click opens the session.
- Turn notifications can be set up on every machine, not just this computer.
- A compact projects list fits many more sessions on screen.

## Terminal

- Copy with the mouse reaches the system clipboard; Shift+Enter makes a new line.
- Links and file:line references are clickable; Find with Cmd+F on macOS,
  Ctrl+Shift+F elsewhere.
- Zoom with Cmd/Ctrl +, − and 0, true colour, terminal titles on the window,
  and bells on background tabs.

## Layout

- The terminal gets the centre of the window; the chat moves to a side column.
- One slim window header, a calmer look, and better contrast.
- Settings (Cmd/Ctrl+,): theme, terminal font size, default agent,
  notifications, memory, update channel and crash reports.
- Keyboard shortcuts that work from inside a terminal, System Health as an
  overlay that keeps your terminals open, and a layout that survives a relaunch.

## Workflow

- Git branch and changes per project, and a diff of what a session changed,
  with comments you can send back to it as a prompt.
- An optional worktree per session, listening ports you can open on this
  computer, and a task that becomes a session in one click.
- Claude and Codex usage per machine, session history with resume, and the
  tmux sessions outside your projects.
- Optional SSH agent forwarding per machine, off by default.
- Importing running tmux sessions from more than five folders asks first.

## Distribution

- A first-run checklist: tmux, Claude Code and Codex (with one-click install
  and sign-in), notifications, and memory.
- Memory is now optional. Nothing is downloaded until you turn it on; machines
  that already have it keep it.
- Installers are named by platform and architecture, Linux gains arm64
  builds and an rpm package, and macOS gains a zip.
- A Homebrew cask is built with each stable release. The tap that serves it
  is not published yet; once it is,
  `brew install --cask abhirajsingh101/dolphin/dolphin-desktop` installs Dolphin.
- A beta update channel for prereleases, in Settings.
- Help → Report an Issue… opens a pre-filled GitHub issue with personal details
  removed. Crash reports stay on your computer, and you can turn them off.
- On macOS 15, open Dolphin the first time from System Settings, Privacy &
  Security, Open Anyway (see the README).
