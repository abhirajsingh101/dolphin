Dolphin 0.2.7 suggests a useful skill every day, adds a Settings button, and shows any connected machine's health.

- **A skill suggestion that actually arrives.** Once a day, with memory on,
  Dolphin now suggests the one well-known skill that would most improve your
  recent work, above the chat. Its searches were too narrow before, so most
  days it found nothing worth showing. Dolphin still never installs a skill;
  it shows the page and the command to run.
- **Settings in the top bar.** A gear beside the theme button opens Settings.
- **Health for every machine.** System Health has a machine menu in its
  header: switch to any machine you are connected to and see its CPU,
  memory, disks, network, GPUs and processes right there. A disconnected
  machine offers Reconnect.
- **Safer helper.** The helper refuses requests that name a foreign host or
  come from another website, which stops a web page from reaching it by
  pointing its own name at your computer.
