Dolphin 0.2.8 opens the file paths your terminals print.

- **Click a path to open it.** In Select Text, or with Cmd/Ctrl-click in a
  terminal, a file path now does the useful thing. On this computer it is
  shown in Finder (or your file manager). On a machine over SSH it is saved
  to this computer's Downloads folder, and the window says when it is there.
- **Downloads without a dialog.** Anything Dolphin downloads goes straight to
  Downloads; a name already taken gets " (1)", " (2)" and so on.
