Dolphin 0.2.4 updates itself on a Mac, and its projects list is easier to read.

- **Updates install themselves on a Mac.** From this version on, a new
  version downloads in the background and Restart to Update puts it in
  place, or it goes in when you quit. Nothing opens in your browser. This
  works when Dolphin runs from a folder you can write to, such as
  Applications; run from the disk image or Downloads, it offers the download
  as before and says why. Updating to 0.2.4 itself still uses the download.
- **A projects list in three levels.** A machine is a band with a laptop or
  server icon and its connection dot. A project has a folder in its own
  colour, and its name keeps its room: the branch takes what is left, and a
  clean main or master is not shown. Sessions sit under their project.
  Buttons that appear on hover no longer take space from names.
- **A wider list when you want one.** Drag the list's right edge, or focus it
  and use the arrow keys. Each window remembers its width; a double click
  goes back to the default.
- **Fullscreen clears the window buttons.** A fullscreen project window
  starts below the top bar, so the window's own buttons no longer sit on its
  tabs.
