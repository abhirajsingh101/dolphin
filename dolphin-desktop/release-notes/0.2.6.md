Dolphin 0.2.6 looks the same everywhere, moves smoothly, and its memory knows what every project has been doing.

- **One glass design on every screen.** Dialogs, menus, Settings, System
  Health, the launch and Connect pages, and the SSH prompts share one glass
  finish, one set of buttons and one style of field, in light and dark. The
  launch and Connect pages follow the theme you pick inside Dolphin. Small
  text and filled buttons read clearly in both themes.
- **Smooth, quiet motion.** Dialogs, the command palette, menus, toasts and
  the hover preview open and close with a short animation. Tabs share one
  marker that slides to the tab you pick, and collapsed sections animate
  shut as well as open. New chat messages arrive with a light motion, while
  history appears in place. Terminals never animate. With Reduce Motion on,
  nothing moves.
- **Memory knows every project's work.** With memory on, the brain on this
  computer reads finished Claude Code and Codex turns on each machine, with
  secrets masked, and keeps a dated timeline on each project's page. A quiet
  project's state, open threads and recent decisions are summed up by your
  own Claude Code or Codex.
- **Search by meaning, with no API key.** Memory searches by meaning with a
  small local model (about 130 MB, downloaded with memory). It understands
  English, Korean and more. Machines over SSH no longer install memory of
  their own; their work reaches this computer's brain instead.
- **Plain terminals and both agents.** New Session offers Claude Code, Codex,
  a tmux session or a plain terminal. Tick Always start this to make + start
  your choice; Option/Alt-click on + still asks. Every feature that starts
  an agent uses the one you prefer, or the other one when it is not
  installed.
- **A new Settings.** Settings is a sectioned page with search, in both
  themes.
- **Skill suggestions.** At most two well-known skills a day may appear above
  the chat composer when they would clearly help your recent work. Dolphin
  never installs them; it shows a link and the install command. Turn them
  off in Settings > Memory.
- **Taller stacked windows.** Drag a stacked session window's bottom edge as
  far as you like; the stack scrolls to make room.
