Dolphin 0.2.11 puts the selected session's todos first.

- **This session.** The Tasks list now opens with the todos that belong to
  the terminal session you have selected, marked in the accent colour. A
  todo belongs to the session that was selected when you added it, or to
  the session its play button started while that session runs. The rest of
  the project's todos stay below under To do.
- **Wrapped paths are links.** In select mode, a long file path that Claude
  Code or Codex wrapped onto the next line now opens as one link.
